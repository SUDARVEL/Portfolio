# Best blend: Sanjay Menon structure × Sudarvel theme

Inspired by [Sanjay Menon](https://sanjaymenon.framer.website/) (via Wall of Portfolios), combined with:
- Our cinematic storyboard theme
- Fedor *Product Design Portfolio Final Final* (RRR + bottom line up front)
- Resume facts + storytelling worksheets

## What we stole from Sanjay (strategy)
- Conversational intro (“Hey, I’m…”)
- Outcome-first project titles + numbered cards (01 / year)
- Metrics on every work card
- Clear “View case study” CTA
- Experience timeline on the home page
- Case studies that explain thinking, not only visuals

## What we kept as Sudarvel (identity)
- Dark cinematic palette (near-black / mauve / sunset coral)
- Storyboard hero (“The view that builds dreams”)
- Brand-first **SUDARVEL**
- No light-blue Framer clone, no copied handwriting/signature

## What we kept from Fedor
- Only **3 RRR** case studies
- **Bottom line up front** (metrics at top of case study)
- Canvas blocks: why → challenge → status quo → process → outcome → learnings
- Lead to contact

## Site map (live)
Home: Hero → Selected work (impact panels) → Experience → About → CTA  
Work / Case study: BLUF metrics → story sections → key decisions → next project  
Resume / Contact / Gallery
